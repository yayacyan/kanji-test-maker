# 第5回：4人のテスト役（山本先生・佐藤さん・はると・田中さん）と修正

評価者はすべて AI。対象：種類カード（絵で選ぶ）、送りがなの読みがな・枠、練習マスの回数、を入れた版。

## 4人が共通して見つけたこと → 修正
| 指摘 | 修正 |
|---|---|
| 答えの漢字（語のどの1字でも）が、他の問題の文や用紙上部の説明文に見える（書き＋読みの用紙で約3割） | 出題時に入れ替えて減らす。測定：小3書き＋読み10問×30回、書き＋読み＋送りがな20問×20回、小1〜6全種類30問×10回で、漏れのある用紙 0（修正前 9/30, 15/20, 9/10） |
| 送りがなの読みがなが語全体で、答えが丸見え／□の数で字数がわかる | 読みがなは漢字の部分だけ。答えの枠は字数がわからない縦長1枠（既定）。3字以上があれば全問の枠をそろえる。字数どおりのマスは設定で選べる |
| 練習マスの数が固定 | 字数 × 書く回数（設定、既定4回、1列10マスまで） |
| なぞり書きで、1字語は自分で書けるマスが1つ | うすい字は最初の1回分だけ |
| 「学年から」の種類カードに説明がない／最後の1種類を外せず無反応 | 短い説明を追加／お知らせを表示 |
| 貼り付けの案内どおりの「花の（　）が出る。\|芽」が□の問題にならない | □の問題（文中の□）になる |
| 説明文に習っていない漢字「残」 | 「のこり」に変更 |
| 警告があっても印刷が止まらない | 印刷ボタンで確認を出す |

## 独立検査（別の AI）
8条件すべて通過。用紙の見た目は、書き・読み・文中の□・自由入力で改版前と完全に一致。

## 直していないこと
- 21問など詰めたときのマス・読みがなの小ささ（用紙に入る量の限界。画面に警告あり）
- 「開く」など小学校の漢字データにない語は読み・例文が空になる
- 同じ漢字を書き→読み→練習の別紙で一括作成する機能
- 自由入力の問題文にある漢字と答えの重なり
- Ctrl+P で直接印刷したときは、警告の確認が出ない
