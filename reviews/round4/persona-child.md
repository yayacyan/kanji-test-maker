# 漢字テストメーカー 小三兒童視角評測（はると）

評測方式：Playwright + Chrome。手機（375x812、touch）操作網站；用「小學3年／書き5・読み5・送りがな3・練習マス2・なぞり書き2（共17問）」製作，轉成 A4縦／A4横／A3横 的 PDF（print media）再轉成 2400px 圖片，實際看圖判斷。mm 為圖片像素實測（A4 寬 210mm = 2400px 換算），並與網站自己顯示的「解答マス 約○mm」對照。
未讀任何原始碼、md、backup、reviews、samples。字型／字級以瀏覽器 computed style 與畫面確認。

## 1. 總合評価：★★★★☆（4／5）

作為「大人印給小孩」的工具，紙面很成熟（教科書體、答案格緊貼題目、說明文用小三讀得懂的字）。扣一顆星是因為：17題塞進 A4 時答案格只有約 7mm（網站自己也說「小さめ」），以及手機首屏有被浮動按鈕蓋住的問題。若題數控制在 10 題左右（A4縦 實測 8.7mm），我會給 ★4.5。

はるとの一言：
「テストみたいで、ちょっとこわいけど、どこに書けばいいかは分かったよ。マスがちいさいから、えんぴつだとはみ出しそう。10もんくらいのほうが書きやすいな。」

## 2. 解いてみた記録（A4縦・17問・実測マス約 6.6〜7.2mm）

「マス」＝答えを書く四角。すべて問題文と同じ「縦の1ブロック（線で区切られた帯）」の中にあり、ブロックごとに丸数字が付いている。

| 問 | 迷ったか | メモ |
|---|---|---|
| 1 四月に、にゅうがくしきがあった。 | 迷わない | 「線のひいてある ひらがなを、漢字で」→線がひらがなの右に引いてある。マスは3つ（入学式の字数）で左隣に縦並び。実測 幅6.8×長さ20.3mm（1マス約6.8mm）。 |
| 2 自転車を しゃこ にしまう。 | 少し迷う | 文が次の列に折れて「う。」だけ列の頭に残る。マスは「しゃこ」の左隣にあるので書く場所は分かる。マス2つ。 |
| 3 この本は やすい ので、二さつ買った。 | 迷わない | 「やすい」全体に線→マス2つ（安い）。文が2列にまたがるが、マスは線の左隣。 |
| 4 かぜをひいたので、くすり を飲む。 | 少し迷う | マス1つ（薬）が「くすりを飲む。」の左の列の一番上にぽつんとある。線の位置とそろっているので分かるが、文と離れて見える（実測でマスは線の左約1列ぶん）。 |
| 5 ぼくの しんちょう は、百三十センチだ。 | 迷わない | マス2つ（身長）。 |
| 6 一列 にならんで歩く。（読み） | 少し迷う | 線が「一列」だけ。マスは縦4つ＝「いちれつ」4字が1字ずつ入る。「一列」と「にならんで」の間が空いていて、「ここに書くの？」と一瞬思う（実際のマスは空白の左隣）。 |
| 7 ねる前に 歯 をみがく。（読み） | 迷わない | マス1つ＝「は」。実測 6.9×6.6mm。 |
| 8 右手の 指 は、五本ある。 | 少し迷う | マス2つ＝「ゆび」。「指」と「は、」の間が大きく空く（マスを置く場所を空けているため）。 |
| 9 運動会で、先生が 笛 をふく。 | 迷わない | マス2つ＝「ふえ」。 |
| 10 お寺の大きな 柱 を見上げる。 | 少し迷う | マス3つ＝「はしら」。「柱」と「を」の間が3マスぶん空く。 |
| 11 バットでボールを打□。（送りがな） | 少し迷う | マス1つ、右上に小さく「うつ」。説明に「右の小さい字は 読みがなです」とあるので分かる。ただし「打」と「□」の間で文が折れる（次の列の頭に「打」）。 |
| 12 夕日がとても美□□。 | 迷わない | マス2つ、右に「うつくしい」（小さい字）。 |
| 13 ハンカチを持□□学校に行く。 | 迷わない | マス2つ、右に「もって」。 |
| 14 有名（ゆうめい） | 少し迷う | 大きなお手本と、マス6つ（縦）。「有名」を3回書くのか、「有」を6回書くのか、説明では分からない（解答用紙を見て「有名有名有名」と分かる）。 |
| 15 調べる（しらべる） | 少し迷う | マス6つ＝「調べる」を2回。3字ことばで6マスは分かりやすい。 |
| 16 昔（むかし） | 迷わない | マス5つ。上2つにうすい字「昔」。「うすい字をなぞってから、残りのマスにも」→分かる。 |
| 17 実（み） | 迷わない | 同上。うすい字は薄いが、印刷ではっきり見える濃さ。 |

(a) 説明文：問題用紙の上に種類別に5行（A4縦）。分かち書き（ことばの間にあき）で、使われている漢字は 線・読・漢字・書・送・手本・同 など。私の記憶では小3までの漢字だが「残」だけは小4（推測）。読めた。ただし文字がとても小さい（下の【実測】参照）。
(d)「読み」のマスに書ける字数：1字ずつ入る縦のマスで、問6=4字、問7=1字、問8=2字、問9=2字、問10=3字。読みがなの文字数ぴったり（マスの数がヒントになる）。
(c) マスの大きさ：実測 約 6.6〜7.2mm（A4縦・17問）。網站表示も「約7.0mm／約16pt」。
(e) こわい・つまらない：白黒だけで絵がないので「テストらしくて、ちょっとこわい・たのしくはない」（推測）。

## 3. 解答用紙を見て、自分の答えと比べる

- 赤い教科書体の字が、そのマスの中にそのまま入る（問1「入学式」、問6「いちれつ」、問14「有名有名有名」）。自分の答えと1マスずつ重ねて比べやすい。【推測】
- 赤枠の四角と赤字なので、「ここに書くのが正解」が一目で分かる。問11「つ」問13「って」など送りがなも1字ずつ赤で見える。
- 見出しに赤い「解答」の枠が付く。名前・点の欄が無い（正しい）。
- 赤字は濃い赤で、紙が白黒印刷だと薄いグレーになる可能性がある（未確認）。

## 4. サイト画面の見た目・直感性（手順8）

以下は全部【推測】（子どもの目ならこう見えるだろう）。画面の見え方は実測（スクショ）。

(a) すっきり／ごちゃごちゃ
- PC：左に「作る」、右に「用紙プレビュー」の2列。すっきりしていて分かる。
- スマホ：上から見出し→01/02/03のカード→学年→問題の数→問題の種類→種類ごとの問題数→問題を作る、と一本道で、順番は分かる。ただし「くわしい設定」の下に大きな空白（約50px）があったり、問題一覧のカードは「学年／漢字／よみがな／答え／例文＋5つのボタン」で情報量が多い（1問あたり約320px）。
- 大人向けの言葉が多い：「学年から」「打つ・貼り付け」「写真・AI」「種類ごとの問題数」「この端末に保存済み」。小3が習っていない漢字（私の記憶では 印刷・種類・保存・解答・編集・複数・設定・削除・一覧）が多い。でもこのサイトの主なお客さんは親・先生なので、これ自体は問題ではない。

(b) 「AIが作ったようなありがちなデザイン」に見えるか：**見える（中〜やや強い）**。理由：
1. 見出し「漢字テストを、数タップで。」に、黄色い蛍光ペン風の下線（「数タップ」）。生成系のLP（紹介ページ）でよくある型。
2. 「01 / 02 / 03」と等幅数字ラベルをつけた3枚のカード（選択中が黒反転）。これも定番。
3. ボタンが全部「黒い丸ごしのピル型」、ヘッダーとタブバーが「ふわっと影のある浮き上がった丸いバー」。iOS風・SaaS風の型どおり。
4. 色は白・黒・グレーだけで、補足文がうすいグレーの小さい字。学校らしさ・子どもらしさ（鉛筆、ノートの罫、教科書体）が画面に一切出ない。紙面は教科書体なのにUIは無個性なゴシック体。
5. 黒いボタンが2つ同時に目に入る（上「印刷 / PDF」と下「問題を作る」）ので、どちらが先か迷う。
一方、紫グラデーションや絵文字だらけではないので、「ひどいAIっぽさ」ではなく「よくできたテンプレ」。

(c) 字の大きさ・ボタン
- ボタン：実測で高さ48px（CSS）以上。「問題を作る」329×54、「印刷 / PDF」約126×48、タブ（編集・プレビュー・解答）110×48、↑↓48×48、コピー67×48、編集55×48、削除55×48、チップ（10問・書き…）高さ48。親指で押せる大きさ。
- 本文の字：説明文15px、ラベル（「学年」「問題の数」）は小さめの灰色（約13px）で、薄くて読みにくい。

(d) 好ましい点／好ましくない点
- 好ましい：一本道で迷いにくい／ボタンが大きい／「17問を作りました　プレビューを見る」の案内が出る／マスの大きさの警告が出る／プレビューで実物が見える。
- 好ましくない：手機首屏で下の「問題を作る」が問題の種類ボタンの上にかぶる（下の困った点を参照）／子ども向けの楽しさがない／灰色の小さい字が多い。

## 5. 所見（【実測】と【推測】を分ける）

### 【実測】（画面・画像・計測ソフトで確かめたこと）
- スマホ375px：横スクロールなし（scrollWidth=375）。ページ全長 1863px（編集タブ）。
- 手機首屏：固定表示の「問題を作る」ボタン（329×54）と下のタブバーが、「問題の種類」の1行目「書き（線のひらがな）」ボタンの下半分と2行目を隠す（m_top.png）。スクロールすると解消する。
- ボタン高さ：上のとおりすべて48px以上。
- 17問を作る：書き5・読み5・送りがな3・練習マス2・なぞり書き2＝17問、指定どおり。1ページに収まる（A4縦・A4横・A3横すべて1ページ）。
- マスの大きさ（1マス）：A4縦 約6.9mm（画像実測 6.6〜7.2）／網站表示 7.0mm、A4横 約6.9mm（画像 6.9mm、網站 6.9mm）、A3横 約10.2mm（画像 10.2mm、網站 10.2mm）。
- 問題数を変えると：10問A4縦＝8.7mm（画像実測 8.6×8.7mm、網站 8.7mm）、10問A4横＝9.1mm、10問A3横＝12.3mm、20問A4縦＝7.3mm、20問A4横＝6.4mm、20問A3横＝9.2mm。網站の「8mm以上」の基準と「約7問までなら8mm以上」の案内は 10問=8.7mm・17問=7.0mm と整合した。
- 字体：問題文・説明文・タイトルの font-family は「UD Digi Kyokasho → UD デジタル 教科書体 → YuKyokasho（游教科書体）→ … Mincho」の順。この Mac には游教科書体が入っており、印刷画像でも教科書体の字形（はね・はらい）になっていた。設定に「書体：教科書体」がある。
- 字の大きさ（網站表示）：A4縦17問＝約16pt、A4横17問＝約16pt（15pt、20問時）、A3横17問＝約23pt。10問A4縦＝約20pt。説明文とふりがなは画面上の比率から約7.5〜8pt（推算値、画像の1字ピッチ約2.8mmとも合う）。
- 解答用紙：すべての種類で赤字が該当マスに入る。

### 【推測】（小3ならこう感じるはず）
- A4縦17問の7mmマスは、えんぴつで書くには小さい（はみ出す子がいそう）。10問で8.7mmならだいぶ楽。網站自身も8mm以上を目安にしている。
- 説明文（約8pt）は小さい。読める子は読むが、読み飛ばす子が多そう。
- 送りがなは、小3では習う項目なので説明文だけで分かる子が多い。ただし例が1つあるともっと安心。
- なぞり書きは「うすい字をなぞってから」で分かりやすい。
- 練習マスは「有名」を何回・どの順に書くかが不明（「くりかえし」だけ）。
- 手機の首屏の浮動ボタンは、子どもが自分で触ると「押せない」と思うかも。
- A4横は幅が広くて1ブロックが細く、A4縦と同じ7mmなので、はると的には「A4縦とあまり変わらない」。いちばん解きやすいのは A3横（10.2mm・23pt）だが、家庭では印刷しにくいのが現実（推測）。総合すると A3横 ＞ A4縦 ≒ A4横。

## 6. 良かった点

1. マスが問題の言葉のすぐ隣（線の左隣）にあり、書く場所がすぐ分かる。どの問題も「丸数字の帯」の中で完結している。
2. 「読み」のマス数＝読みがなの字数、「書き」のマス数＝漢字の字数（送りがなを含む）で、手がかりになる。
3. 説明文が問題の種類ごとに分かれ、分かち書き・小3までの漢字が中心で読める。
4. 教科書体で、手本にそのまま使える字形。なぞり書きのうすい字はほどよい濃さ。
5. 解答用紙が赤字＋赤枠で、自分の答えと重ねて比べやすい。
6. 網站が「マスが小さい」と警告し、何問までなら8mmになるかまで教えてくれる（PC版・手機版とも黄色い枠）。
7. ボタンが大きく（48px以上）、手機でも操作しやすい。
8. 印刷の説明文（「できたら右上の『印刷 / PDF』を押します」）がある。

## 7. 困った点・直してほしい点

### 必ず直す
1. 手機首屏で「問題を作る」浮動ボタンが「問題の種類」チップにかぶる（m_top.png：「書き（線のひらがな）」が半分、「読み（線の漢字）」「書き（文中の□）」がほぼ隠れる）。スクロール前の一番大事な選択が見えない。ボタンを固定でなく通常の位置に置く、または首屏では出さない。
2. 17問×A4（縦・横）で答えマスが約6.9〜7.0mm（20問A4横は6.4mm）のまま印刷できてしまう。警告は黄色い文だけ。子どもの鉛筆には小さすぎるので、8mmを切るときは「印刷 / PDF」ボタンの近くにも警告を出す、または自動で「12問ずつ2枚に分ける／A3にする」を提案する。

### 直したほうがよい
3. 問題用紙の説明文（約8pt）とふりがな（約8pt）が小さい。「11〜13 □に 送りがなを 書きましょう。（右の小さい字は 読みがなです）」は特に。10ptまで上げたい。
4. 問16・17の説明文にある「残」は小4の漢字（私の記憶による推測）。「のこりの」とひらがなにする。
5. 問6・8・10：下線の言葉と続きの言葉の間が大きく空く（例：問8「右手の指　は、五本ある」、問10「柱　を」）。「ここに書くの？」と迷う。空きは残しても、そこを薄い点線などで「マスは左にあります」と分かるようにするか、間を詰める。
6. 問2「う。」問8「る。」問6「く。」のように、文の最後の1〜2字だけが次の列の頭に残る。読みにくいので、文全体を1列に収めるか、折り返し位置を動かしたい。
7. 問14・15（練習マス）で「有名」を何回・どの順に書くかが分からない。説明に「（例：有名 有名 有名）」を入れる。
8. 送りがなの説明に例が無い。「例：打（う）つ → 打□ に『つ』を書く」と1つ入れる。
9. 手機のプレビューは41%で、そのままでは字が読めない（＋を4回押して100%で読める）。首屏で「拡大して見る」を押す案内がほしい。
10. 手機の「くわしい設定」の下の大きな空白、トースト（「17問を作りました」）が見出しにかぶる。
11. 黒い大ボタンが2つ（「印刷 / PDF」と「問題を作る」）で、先に押すのはどっちか分かりにくい。「問題を作る」だけ強調して、「印刷」は「プレビュー」後に強調する。

### あればうれしい
12. 見出し・ボタンをもう少し子どもや学校らしく（例：教科書体の見出し、ノートの罫の背景、色1つ）。
13. 灰色の補足文（約13px、薄い）をもう少し濃くする。
14. 問題用紙に小さなイラストや「がんばろう！」の一言（点数欄の近く）。「こわい」を減らせる。
15. 「印刷 / PDF」を押す前に、10問／20問／A3にすると何mmになるかの比較表を出す。

## 8. 確認できなかったこと（正直に）

- 本物の9歳児ではないので、上の【推測】は全部「そう感じるはず」の想像であり、実際の子の反応は未確認。
- 実際に紙に印刷して鉛筆で書いてはいない。PDF（Chromeの print emulation + page.pdf）を画像にして mm を測った。プリンタ側の余白・拡大縮小・A3実機での出力は未確認。
- 教科書体は、この Mac には游教科書体が入っている。Windows・iPad・Chromebook・学校のPCなど、教科書体が入っていない端末で明朝にフォールバックするかは未確認。
- 実機のスマホ（iPhone Safari・Android Chrome）は未確認。Chrome のモバイルエミュレーション（375x812）のみ。
- 「写真・AI」「自分で」タブは開いて画面を見ただけで、入力・読み取りは試していない。「書き（文中の□）」「自由入力」「名前をつけて保存」「別の端末で使う」も未使用。
- 「印刷 / PDF」ボタンを押した後の実際の印刷ダイアログは見ていない（emulate_media で代用）。
- 漢字の学年配当（例：「残」は小4）は私の記憶による推測で、学習指導要領の表では照合していない。
- 問題は乱数で選ばれるため、私の1回分の17問・10問・20問の結果しか見ていない。別の抽出で長い文が出た場合の折り返しは確認していない（今回の17問では、はみ出し・ページ溢れはなかった）。
